# rallyreplay-ai
#Project: RallyReplay AI
#Problem: Reviewing full-length volleyball recordings to find highlights and compile statistics takes significant manual effort.
#Solution: Develop a web application that lets players upload match footage, annotate volleyball events, calculate player/team statistics, and receive AI-assisted rally and highlight suggestions.
#MVP features:
#- Upload and play a volleyball recording.
#- Identify and manually tag rallies and player actions.
#- Calculate kills, digs, aces, attack attempts, and rally durations from confirmed events.
#- Display match and player statistics.
#- Trim and export highlight clips.
#AI goals: Suggest rally boundaries, rank potential highlights, and eventually classify selected volleyball actions.
#Out of scope for the first release: Fully automated identification of every player and every volleyball statistic.
